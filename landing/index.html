Cara kerja

Dari nol ke agen yang bekerja dalam tiga langkah.

1

Pilih server

Tentukan ukuran dan lokasi. Server dibuat otomatis dengan snugcode, Git, Node, Python, dan Docker terpasang.

2

Hubungkan dari HP

Masuk dengan GitHub, buka PWA, dan server langsung muncul di daftar mesin. Tanpa SSH, tanpa port forwarding.

3

Beri arahan & deploy

Minta agen membangun fitur, setujui diff-nya, lalu tap deploy. Aplikasimu live di server yang sama.

FAQ

        
Pertanyaan yang sering muncul.

        
Belum terjawab? Tanya langsung lewat GitHub atau email.

      

      

        
snugcode tetap open-source dan gratis dijalankan di PC-mu. snugcode Cloud memberimu server yang selalu menyala, sehingga agen tetap bekerja saat laptop mati, dan server yang sama bisa menjalankan aplikasimu.

        
Tidak. Kamu memakai API key atau langganan Claude, OpenAI, maupun Gemini milikmu sendiri, jadi tidak ada markup token. Kami hanya menagih servernya.

        
Tentu. Ini VPS sungguhan dengan akses shell penuh. Deploy repo apa pun — frontend statis, API, container Docker, worker, maupun database.

        
Koneksi HP ke server terenkripsi end-to-end; relay hanya meneruskan data terenkripsi. Setiap server terisolasi, dan kunci API disimpan terenkripsi di server milikmu.

        
Bisa. Ubah ukuran server dari dasbor; tagihan dihitung prorata per jam. Data dan aplikasi tetap aman saat resize.

        
QRIS, transfer bank, e-wallet, dan kartu kredit. Tagihan tahunan mendapat potongan 20%.
