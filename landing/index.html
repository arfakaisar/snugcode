Features

Everything you need to code from anywhere.

One server, two jobs: a home for your coding agent, and a place for your apps to live.

Always on

Your agent works while you sleep.

Close the laptop, lock your phone. The server runs agent sessions to the end and pings you when it needs your approval.

Security

End-to-end encrypted.

The relay only forwards ciphertext. Your code and API keys are never readable in transit.

Parallel

A worktree per session.

Run several agents at once without stepping on each other. Every session gets its own branch.

How it works

From zero to a working agent in three steps.

1

Pick a server

Choose a size and region. It comes up with snugcode, Git, Node, Python and Docker preinstalled.

2

Connect from your phone

Sign in with GitHub and open snugcode agent. Your server is already in the list. No SSH, no port forwarding.

3

Direct & deploy

Ask the agent for a feature, approve the diff, tap deploy. Your app goes live on the same server.
